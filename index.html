1) Casi validi wrapper (nuovo dominio)

  • Giochi (tab giochi)
  • Podcast (tab podcast)
  • Homepage (tab news)
  • Articolo (dettaglio)
  • Altro link (dettaglio o tab se matcha carosello)
  • Link esterno

2) Wrapper invalidi (fallback home app)

  • Manca parametro url
  • Parametro url vuoto

3) Link non-wrapper (flusso normale)

  • Homepage diretta
  • Giochi diretto
  • Podcast diretto
